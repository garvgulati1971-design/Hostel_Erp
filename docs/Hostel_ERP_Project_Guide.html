2. 👥 The Three Role Portals

1. 👤 Student Portal

  • Dashboard: Real-time attendance rate (94.2%), fee balance, active outpasses, and mess menu.
  • Gate Outpass Manager: Apply for day/night outpasses with AI risk scoring and QR gate pass generation.
  • Maintenance Requests: Submit tickets for plumbing, electrical, WiFi, or housekeeping.
  • Fees & Receipts: Detailed fee breakdown with online payment simulation and printable receipts.
  • AI Helper Chatbot: Conversational NLP assistant for hostel queries.

2. 👨‍💼 Warden & Administration Portal

  • Scalable Student Database Directory: Search and paginate 50+ student records with filter controls.
  • Disciplinary Warnings System: Issue official written warnings to students (Curfew Violation, Noise Complaint, Mess Misconduct) with parent SMS notification.
  • Outpass Approvals: Review outpasses flagged with AI risk levels before final decision.
  • Emergency Broadcasts: Dispatch instant alerts across all student dashboards.

3. 🛠️ Service Staff & Maintenance Portal

  • Technician Task Queue: View tickets filtered by discipline (Plumbing, Electrical, HVAC, WiFi).
  • Status Updater: Update ticket state (Pending -> In Progress -> Resolved) with repair notes.
  • Simulated SMS Gateway: Real-time SMS logs and smartphone mockup modal demonstrating live SMS delivery to technicians.

3. 🔍 Key Code Lines Explained

A. Database Indexing & Scalability (backend/db.js)

// WAL Mode enables concurrent reads while writing
db.pragma('journal_mode = WAL');

// B-Tree SQL Index for fast roll number queries
CREATE INDEX IF NOT EXISTS idx_students_roll ON students(roll_no);

Java Explanation: WAL prevents database locking, while B-Tree indexing makes finding a roll number fast even across 100,000 records.

B. Paginated Database API (backend/server.js)

app.get('/api/students', (req, res) => {
    const page = parseInt(req.query.page) || 1;
    const limit = parseInt(req.query.limit) || 10;
    const offset = (page - 1) * limit;

    const students = db.prepare('SELECT * FROM students WHERE name LIKE ? LIMIT ? OFFSET ?')
                      .all(search, limit, offset);
    res.json({ success: true, page, data: students });
});

Java Explanation: Like Spring Data Pageable, LIMIT and OFFSET prevent memory overload by fetching only 10 rows per page.
